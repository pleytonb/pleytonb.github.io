# Mi rclone

Mi rclone es una configuración de uso personal de rclone para copiar archivos desde mi cuenta de Dropbox a mi cuenta de Google Drive.

El acceso a Google Drive se autoriza mediante Google OAuth y se utiliza para realizar las transferencias solicitadas por el propietario de las cuentas.

Este sitio contiene únicamente información sobre esta configuración. No recibe archivos ni credenciales.
